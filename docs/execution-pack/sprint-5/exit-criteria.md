# Sprint 5 — Exit Criteria

Sprint 5 dinyatakan complete jika:
- KPI reliability membaik dibanding baseline Sprint 4.
- Tidak ada major incident open saat closure.
- SLO/SLI + alert policy disetujui lintas fungsi.
- Hardening backlog P0/P1 selesai sesuai komitmen.
- Artefak RCA dan recon automation terdokumentasi.
