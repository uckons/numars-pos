# Sprint 5 — Change Guardrails

## Deployment Guardrails
- Tidak deploy perubahan high-risk di jam tutup operasional.
- Perubahan schema wajib backward-compatible selama sprint.
- Fitur baru high-impact harus behind feature flag.

## Freeze Rules
- Freeze 24 jam sebelum closure gate.
- Hotfix hanya untuk Sev-1/Sev-2 dengan approval lintas owner.
