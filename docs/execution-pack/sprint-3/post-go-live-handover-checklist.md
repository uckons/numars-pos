# Sprint 3 — Post Go-Live Handover Checklist

Checklist ini dipakai setelah rollout wave selesai untuk memastikan transisi dari mode proyek ke mode operasional harian berjalan rapi.

## 1) Operational Handover

- [ ] Ownership runbook dipindah ke tim operasi (on-duty roster jelas).
- [ ] Jadwal recon harian difinalkan (jam + PIC).
- [ ] Channel incident dan escalation matrix dikunci.
- [ ] Dashboard monitoring diserahkan ke owner bisnis + tech.

## 2) Data Integrity Closure

- [ ] Tidak ada jurnal `POSTED` unbalanced pada window H+3.
- [ ] Tidak ada duplicate posting yang unresolved.
- [ ] Semua mismatch recon punya status closed / accepted with RCA.
- [ ] Sampling audit trail (submit/approve/reject) tervalidasi lengkap.

## 3) Product & Process Closure

- [ ] Feature flag strategy pasca-rollout diputuskan (tetap gated / default ON).
- [ ] SOP maker-checker dipublikasikan ke user accounting.
- [ ] Daftar known limitations dan workaround diperbarui.
- [ ] Backlog improvement Sprint berikutnya sudah diprioritaskan.

## 4) Documentation Closure

- [ ] README sprint-3 diperbarui ke status final `PASS` (jika terpenuhi).
- [ ] Task board ditutup dengan tanggal final close.
- [ ] Runbook + checklist diberi versi dan tanggal efektif.
- [ ] Evidence pack disimpan (log recon, incident timeline, sign-off).
